# AI Tracker Discriminator Checkpoints & Weights

This directory is the sole canonical local location for the AI Tracker
(getpixelvideo.py):

  - Online-discriminator checkpoints: discriminator_<profile>.npz
    (default: discriminator_default.npz). Updated across sessions (JIT /
    transfer learning); kept local to the user/machine.
  - Backbone ImageNet weights (scientist-visible, reusable, retrainable):
      resnet50_imagenet.pth          (default primary)
      resnet152_imagenet.pth         (optional)
      mobilenet_v3_small_imagenet.pth (optional, CPU-friendly)
      efficientnet_b0_imagenet.pth   (optional, CPU-friendly)

When Deep NN is enabled and a variant has no file here, getpixelvideo prompts:
  1 = Browse an existing .pth/.pt
  2 = Download a clean official torchvision ImageNet checkpoint into THIS folder

Torch hub cache (~/.cache/torch/hub/checkpoints/) is never the permanent home.
If a matching file is found only there, vailá copies it here once and prints the
destination path so the weights stay easy to find on Linux, macOS, and Windows.

Do not commit large weights or user-specific .npz models to git
(vaila/models/ai_tracker/* is gitignored except *.txt).
