SAM 3D Body (facebook/sam-3d-body-dinov3) — gated on Hugging Face.

On EVERY machine (weights are gitignored; do not commit .ckpt/.pt):

1. Accept the license (browser, once per HF account):
   https://huggingface.co/facebook/sam-3d-body-dinov3
2. Sync a current checkout so huggingface-hub >= 1.22 (fixes Exit:0 / 0.00B stalls):
   bash bin/setup_pyproject.sh --target=linux-cuda --extras=gpu,sam,fifa --yes
3. Log in:
   uv run hf auth login
   uv run hf auth whoami    # must exit 0, no traceback
4. Download (preferred — clears locks, uses Hub API):
   bash bin/setup_fifa_sam3d.sh
   # Windows: pwsh bin/setup_fifa_sam3d.ps1

Expect: model.ckpt, assets/mhr_model.pt under this folder.

Stuck at "Downloading (incomplete total...): 0.00B"?
  find .cache/huggingface/download -name '*.lock' -delete
  then re-run setup_fifa_sam3d.sh

Full guide: docs/huggingface_setup.md
See also: CONTRIBUTING.md (vailá models) · https://github.com/facebookresearch/sam-3d-body
