viewc3d_pyvista

Version: 0.3.121 · Updated: 04 September 2026 · File: vaila/viewc3d_pyvista.py · Backend: PyVista (VTK)

VTK-based 3D viewer for C3D and CSV marker data. Multi-C3D overlay with per-file colors and a synced master timeline (Open3D Ctrl+L parity). Part of vailá.

To run

uv run vaila/viewc3d_pyvista.py -i path/to/file.c3d
uv run vaila/viewc3d_pyvista.py -i a.c3d b.c3d
uv run vaila/viewc3d_pyvista.py path/to/one.c3d

Omit paths for a multi-select dialog. Terminal prints script= and a >> Equivalent CLI mirror.

Multi-file

  • CLI: -i/--input one or more paths
  • Startup: multi-select dialog
  • Runtime: key L loads more C3Ds
  • File 0 = Orange (C cycles file 0 only); extras get fixed palette colors
  • Master FPS = highest by default; mismatch prompt can downsample to lowest

Shortcuts

See view3d_pyvista_help.html (also opened with H in the viewer).
