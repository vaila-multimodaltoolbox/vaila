Time Scatter

Plots selected columns vs a usable Time/Tempo/Frame column when present; otherwise vs sample index. Single-column force CSVs (e.g. only fz_N) plot correctly instead of producing 0 series.

Joint Angles

Button Joint Angles loads long-format *_joint_angles.csv (frame, person_id, joint_name, euler_x/y/z_deg). Pick person + joint (defaults prefer left/right knee). Optional fs (Hz) → X in seconds; else X = frame. Y curves (deg): Flexion/Extension, Abduction/Adduction, Internal/External Rotation — display aliases for Cardan XYZ columns.
