vailá — Help Index

Versatile Anarcho Integrated Liberation Ánalysis — open-source Python 3.12 multimodal toolbox for biomechanical and movement analysis (IMU, MoCap, markerless 2D/3D, EMG, force plates, GNSS/GPS, and more), with a Tkinter desktop GUI.

  • Frame A — File manager (rename, import/export, copy/move, tree, find, SSH)
  • Frame B — Multimodal analysis pipelines
  • Frame C — Data, video/image, and visualization tools
