extractpng.py — Video ↔ PNG

Version: 0.3.131
Updated: 09 September 2026

Part of vailá. High-performance video-to-PNG extraction and PNG-to-video creation accelerated by NVIDIA GPU hardware (NVDEC decoding & NVENC encoding via FFmpeg CUDA) with automatic CPU software fallback.

Key Optimizations & Features

  • NVIDIA GPU Decoding (--hwaccel auto|cuda|cpu): Auto-detects NVIDIA GPUs (e.g. RTX 4090) and decodes streams directly on hardware with NVDEC via -hwaccel cuda.
  • Fast Lossless PNG Extraction (-c / --compression 0-9): Defaults to fast level 1 with -pred none, speeding up extraction ~3x while maintaining bit-for-bit lossless pixel parity.
  • Redundant Rescaler Bypass: Skips unnecessary CPU Lanczos/bicubic resampling when target dimensions match native video.
  • Parallel Multi-Video Batching (-j / --workers): Multi-threaded video extraction using ThreadPoolExecutor to saturate NVDEC and CPU cores.
  • NVIDIA NVENC Video Creation: Fast encoding of PNG sequences to MP4 via h264_nvenc and hevc_nvenc.

GUI

Frame C → Video and Image → C_B_r1_c1 - Video<-->PNG, or:

uv run vaila/extractpng.py
  1. Check the detected GPU hardware acceleration badge.
  2. Choose mode: Video → PNG / PNG → Video / Select frames.
  3. Browse input (output optional).
  4. Select acceleration mode, compression speed, and parallel workers.
  5. Click Run (prints copy-paste CLI mirror).

CLI

# Fast GPU extraction with auto-detected CUDA and level 1 compression:
uv run vaila/extractpng.py extract -i /path/to/videos

# Explicit GPU acceleration with 4 parallel workers:
uv run vaila/extractpng.py extract -i /path/to/videos -o /path/to/out --hwaccel cuda --compression 1 --workers 4

# Create video using GPU NVENC hardware encoder:
uv run vaila/extractpng.py create -i /path/to/png_dirs --fps 30 --codec 264_nvenc --hwaccel cuda

# Grab select frames with GPU acceleration:
uv run vaila/extractpng.py frames -i VIDEO.mp4 --frames 0,3,5,7 --hwaccel cuda

Notes

  • FFmpeg -hwaccel cuda is placed before -i (input option).
  • Default PNG pattern: %09d.png.
  • Batch extraction generates video_info.txt in each directory detailing FPS and GPU profile.
