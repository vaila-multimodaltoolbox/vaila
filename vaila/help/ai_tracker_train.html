Train AI Tracker

vailá · Version 0.4.4 · Updated 2026-09-18

Offline fine-tuning for Track AI backbones (.pth) and discriminator checkpoints (discriminator_*.npz) using datasets from getpixelvideo Save ML (pose or detect).

Workflow

  1. getpixelvideo: mark targets, Rename slots to COCO/custom classes.
  2. Save ML → 1=pose or 2=detect.
  3. Main GUI → Markerless 2D → Train AI Tracker.
  4. Pick data.yaml + base .pth, mode backbone / discriminator / both.

CLI

uv run --no-sync python -m vaila.ai_tracker_train \
  --data /path/to/data.yaml \
  --weights vaila/models/ai_tracker/resnet50_imagenet.pth \
  --mode both --epochs 10 --profile athletics

Outputs land under vaila/models/ai_tracker/. ImageNet base weights are never overwritten automatically.
