C3D Metadata Editor & Creator (c3d_metadata.py)

Category: Data Files  |  Version: 0.3.131  |  Updated: 2026-09-09
GUI: Frame C → Data Files → C3D Metadata (C_A_r2_c2)
CLI: Yes (uv run vaila/c3d_metadata.py or uv run vaila.py --metadata)

Purpose

C3D is the biomechanics standard binary format for motion capture marker coordinates and synchronized analog signals (force plates, EMG). The c3d_metadata.py module provides an end-to-end tool to:

  • Inspect C3D Metadata: View manufacturer details, point frame rate (FPS), point coordinates units, marker count, frame count, analog channels, analog sampling rate, subframe ratio, force platforms, and events.
  • Edit Existing C3D Files: Modify point frequency, coordinates units (with automatic coordinate scaling between mm and m), analog sampling rates, manufacturer name, and software tag.
  • Synchronize Analog Invariants: Automatically maintains ANALOG:RATE = POINT:RATE * subframe_ratio, preventing frame count mismatch errors when saving.
  • Sanitize Character Encoding: Cleans Latin-1 / non-ASCII units (such as mm/s²) to UTF-8 before passing to C++ ezc3d SWIG bindings, preventing write crashes.
  • Create New C3D Template Files: Generate clean, valid C3D files with user-defined frames, markers, analog channels, and sample rates.

GUI

Click C3D Metadata in Frame C (C_A_r2_c2) or select C3D Metadata (Edit/Create) inside the C3D <--> CSV dialog.

CLI Usage

# Launch GUI
uv run vaila/c3d_metadata.py
uv run vaila.py --metadata

# Inspect metadata headlessly
uv run vaila/c3d_metadata.py --show /path/to/trial.c3d

# Modify C3D parameters
uv run vaila/c3d_metadata.py -i input.c3d -o output.c3d --fps 120.0 --point-units m --scale-coords --manufacturer "Qualisys"

# Create a new template C3D file
uv run vaila/c3d_metadata.py --create -o template.c3d --fps 100 --frames 200 --markers 10 --analogs 8
