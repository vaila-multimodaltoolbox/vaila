SAM3+Sapiens2 (sam3sapiens2.py)

Version: 0.3.89  |  Updated: 2026-08-01
GUI: Frame B → YOLO + FB → SAM3+Sapiens2
Runtime: NVIDIA CUDA; SAM3 and Sapiens2 optional stacks.

Retomada: use --resume RUN_DIR -i INPUT_DIR; somente resultados com cobertura completa comprovada são reutilizados.

Purpose

This pipeline makes SAM3 the authority for person detection, silhouettes, and persistent IDs. Sapiens2 runs top-down only on the supplied SAM boxes, with one contour-focused image per person. DETR is disabled and never loaded.

  1. SAM3 writes sam_tracks.csv and sam_contours.json.
  2. The contour defines a tight padded pose box and isolates the person from competing crop background.
  3. Sapiens2 estimates 308 keypoints only for those objects.
  4. Outside-contour keypoints have confidence attenuated.
  5. stable_id == person_id == sam_obj_id; no Sapiens Re-ID can swap the IDs.
Optimization: duplicate full-frame DETR inference is eliminated, and Sapiens2 receives only SAM-confirmed people.

Run

In the GUI, use Dir… to batch every video in a folder (non-recursive) or File… for a single clip. Running the script without -i and -o opens the same settings GUI. The dialog is centered and raised above the terminal, and the terminal confirms when it has been mapped. For a terminal-only run, supply both arguments together (-i may be a folder).

uv run python -u vaila/sam3sapiens2.py \
  -i /path/to/videos -o /path/to/output \
  -t person --model 1b --stride 1 \
  --bbox-padding 0.12 --contour-margin 8

Reuse an existing SAM batch without rerunning segmentation:

uv run python -u vaila/sam3sapiens2.py \
  -i /path/to/videos -o /path/to/output \
  --sam-results /path/to/processed_sam_20260730_113024 \
  --model 1b --stride 1

Validate matching and metadata without inference:

uv run python -u vaila/sam3sapiens2.py -i VIDEOS -o OUT \
  --sam-results PROCESSED_SAM --dry-run

Main controls

FlagDefaultEffect
--bbox-padding0.12Context around the tight contour box.
--contour-margin8 pxDilates the silhouette for crop focus and keypoint validation.
--outside-contour-factor0.25Confidence multiplier outside the silhouette.
--max-persons32Safety cap; keeps strongest score×area objects.
--stride1Pose frequency; gaps follow the current SAM box and ID.
--no-contour-focusoffKeep SAM boxes/IDs but use the original crop background.
--sam-resultsnoneReuse an existing per-video or batch SAM run.

Outputs

  • <video>_sam3sapiens2_overlay.mp4: contour, bbox, SAM ID, and Sapiens skeleton.
  • <video>_sam3sapiens2_predictions.json: 308 keypoints and full provenance, including detr_loaded: false.
  • sam3sapiens2_id_audit.csv: frame-by-frame proof of SAM ID inheritance.
  • <video>_markers.csv, sapiens_vaila_*.csv, sapiens_points.csv: getpixelvideo / REC2D / REC3D.
  • Wide per-ID Sapiens pose CSVs, summary JSON, and README_sam3sapiens2.txt.

When SAM is run automatically, raw SAM artifacts live in <video>/sam3/. Reused SAM results are referenced rather than copied.

Setup

bash bin/setup_pyproject.sh --target=linux-cuda --extras=gpu,sam,sapiens --yes
bash bin/setup_sapiens2.sh
uv run hf auth login
uv run vaila/vaila_sam.py --download-weights

See also SAM3 help and Sapiens2 help.

Resume a partial / failed run

uv run python -u vaila/sam3sapiens2.py \
  -i /path/to/videos \
  --resume /path/to/processed_sam3sapiens2_YYYYMMDD_HHMMSS \
  --model 1b

Skips only summaries marked completed=true with the source frame count. Local SAM is reused only when sam_frames_meta.csv covers every source frame; a partial sam_tracks.csv is rerun. Between SAM3 and Sapiens2, descendants are terminated and free VRAM must return to the pre-SAM baseline.
