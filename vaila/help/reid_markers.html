Python Version: 3.12.9

Description:
------------
This tool allows correcting identification issues in marker files generated
by getpixelvideo.py. It offers the following functionalities:

1. Marker merging: Combine markers that represent the same object
2. Gap filling: Fill gaps where a marker temporarily disappears
3. Swaps: Fix cases where IDs were swapped in certain frame intervals
4. Geometric ReID: stabilize marker IDs using 2D distance, velocity direction, and optional homography

================================================================================

SAM tracking CSV support

If sam_tracks.csv is selected, the loader now normalizes SAM long-format tracks to vailá wide marker columns. When a sibling sam_points.csv exists, it is used directly; otherwise the loader writes sam_tracks_reid_points.csv and sam_tracks_reid_id_map.csv.

Geometric ReID v2: schema auto-detection + max_ids merge (v0.3.102)

Upgrades "Geometric ReID (2D + velocity)" to merge an arbitrary number of fragmented raw tracker ids down into <= max_ids persistent trajectories, and to run headless via a new CLI.

  • Schema auto-detection (detect_input_schema): bbox wide-per-slot (X_min_person_id_01 etc., the all_id_detection.csv convention), vailá's pN_x/pN_y point convention, row-per-detection bbox (x1,y1,x2,y2 or x,y,w,h), and SAM long tracks — no manual column picking.
  • max_ids: bounds the number of concurrently active identity slots (a slot idle past --reid-max-gap frees for reuse by a different subject later); omit to auto-estimate from peak simultaneous detections. Reuses the shared GeometricFrameLinker (geometric_reid.py) via its new max_tracks slot pool — no second Hungarian/IoU implementation.
  • No detections dropped, except the one honestly-reported edge case where a single frame has more simultaneous detections than max_ids allows (forced_reassignments/dropped_rows in the printed stats).
  • CLI: uv run python -u -m vaila.reid_markers --input all_id_detection.csv --max-ids 16 --output-dir processed_reid_maxids/
  • GUI: the existing button now tries schema auto-detection first, falling back to the legacy swap-fixer for unrecognized files.

Validated on a real 16,693-frame file: 388 raw fragmented ids merged to exactly max_ids=18 (true peak was 21, so dropped_rows=475 honestly reported the shortfall; max_ids=21 gave dropped_rows=0).
