Manual Video Cuts

Version: 0.4.12 · Updated: 2026-10-28
File: vaila/manual_video_cuts.py (export backend)
GUI: Frame C → Make Sync file → Manual cuts side by side (M)

Independent video trims with inclusive Start/End and manually removed frames. The GUI lives in syncvid.py; this helper validates edits and exports exact selected originals. See the complete GUI/CLI workflow.

Save all or the active camera into a new folder. Output preserves source FPS and decoded pixels, without audio, synchronization, interpolation or automatic count adjustment. CSV maps and manual_cuts.json support audit and replay. Incomplete exports retain INCOMPLETE.txt.

uv run --no-sync python -m vaila.syncvid --manual-cuts -i /path/to/videos
uv run --no-sync python -m vaila.syncvid --manual-cuts -i /path/to/videos \
  --cuts-file /path/to/export/manual_cuts.json --output-dir /tmp/new_manual_export
