interp_smooth_split

vailá CSV/C3D gap-fill / smooth / optional resample tool. Version 0.3.115 · Updated 26 August 2026. Shared core: vaila/interp_smooth_core.py (GUI ↔ CLI parity). C3D uses the same bridge as Edit CSV/C3D (c3d_markers_to_dataframe → process → auto_create_c3d_from_csv).

Pipeline

CSV  → validate → gaps → smooth → optional resample → CSV
C3D  → marker CSV → same pipeline → C3D (labels, RATE, UNITS, residuals, analogs)

Sampling-rate semantics

ConceptMeaning
Butterworth fsFilter sampling frequency (Hz / FPS)
Time Column Sample Rate OverrideRebuild Time only; does not replace Butterworth fs
Original / Final rateOptional final resampling

Columns named Time/t/tempo and frame/frames/frame_index are index axes, never signals: they are excluded from gap filling, smoothing and resampling interpolation regardless of their position in the file.

After resampling, index columns are rebuilt. frame-first CSVs keep integer frames 0 … N−1 with no synthetic Time column. Padding adds and removes exactly the same number of rows per edge, so row count is preserved when resampling is off.

Cutoff must satisfy 0 < cutoff < fs/2 (no silent clamp).

CLI examples

uv run vaila/interp_smooth_split.py -i ./data

uv run vaila/interp_smooth_split.py -i ./data --smooth-method butterworth \
    --fs 100 --cutoff 10 --filter-order 4

uv run vaila/interp_smooth_split.py -i ./data --smooth-method savgol \
    --window-length 7 --polyorder 3

uv run vaila/interp_smooth_split.py -i ./data --time-column-rate 240

uv run vaila/interp_smooth_split.py -i ./data --resample \
    --original-rate 100 --final-rate 50

uv run vaila/interp_smooth_split.py -i ./data --resample \
    --original-rate 30 --final-rate 60

Precedence: explicit CLI flags > TOML > defaults.
