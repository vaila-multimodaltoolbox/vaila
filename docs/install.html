vailá — Install & Run Guide

Detailed, platform-by-platform install and troubleshooting for Linux, Windows, and macOS. For the quick one-liners and GUI/CLI overview, see README.

Quick jump: Linux Windows macOS

Linux

One-line install

wget -qO- https://raw.githubusercontent.com/vaila-multimodaltoolbox/vaila/main/install_vaila_linux.sh | bash

Clone-first install (recommended)

git clone https://github.com/vaila-multimodaltoolbox/vaila.git
cd vaila
bash install_vaila_linux.sh

What install_vaila_linux.sh does

  1. Installs system dependencies via apt; self-installs uv if missing.
  2. Pins Python 3.12.14.
  3. Detects an NVIDIA GPU and prompts for optional extras (gpu, sam, sapiens, fifa).
  4. Copies the matching template (pyproject_linux_cuda12.toml or pyproject_universal_cpu.toml) over pyproject.toml before creating the virtual environment.
  5. Runs uv lock / uv sync --extra ... with fallback logic; verifies CUDA wheels and the Sapiens2 editable install when selected.
  6. Adds a desktop entry and SSH-transfer setup for the File Manager.

GPU vs CPU-only

NVIDIA CUDA 12.8 + TensorRT is used automatically when a compatible GPU is detected; otherwise CPU-only. See README's Cross-Platform support note for the full matrix (SAM 3 video needs CUDA — no CPU/MPS path).

Troubleshooting

  • Permission denied (publickey) during Git LFS / clone / update check: your origin remote is SSH-based; re-clone with HTTPS instead, or add a GitHub SSH key.
  • If uv sync fails partway through an extra, re-run the install script — it re-applies the template and retries idempotently.

Windows

One-line install (PowerShell)

[Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor 3072; irm https://raw.githubusercontent.com/vaila-multimodaltoolbox/vaila/main/install_vaila_win.ps1 | iex

Clone-first install (recommended)

git clone https://github.com/vaila-multimodaltoolbox/vaila.git
cd vaila
powershell -ExecutionPolicy Bypass -File .\install_vaila_win.ps1

SSH clone on Windows: if checkout fails on a Git LFS asset with Permission denied (publickey), clone with HTTPS (above) instead of an SSH remote.

What install_vaila_win.ps1 does

  1. Self-installs uv (winget or official installer) if missing.
  2. Pins Python 3.12.14.
  3. Detects an NVIDIA GPU and prompts for optional extras (gpu, sam, sapiens, fifa).
  4. Copies the matching template (pyproject_win_cuda12.toml or pyproject_universal_cpu.toml) over pyproject.toml before uv venv/uv sync.
  5. Runs uv lock / uv sync --extra ... with fallback logic.
  6. Adds PowerShell/batch launchers, Desktop and Start Menu shortcuts, and a Windows Terminal profile.

GPU vs CPU-only

NVIDIA CUDA 12.1 + TensorRT is used automatically when detected; otherwise CPU-only. See README's Windows section for the Local/Portable vs profile-install path choice.

Troubleshooting

  • "Running scripts is disabled": run Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass first, or use the -ExecutionPolicy Bypass -File form shown above.
  • Permission denied (publickey) when checking for updates: your git origin remote is SSH-based; re-clone with HTTPS or configure a GitHub SSH key.

macOS

One-line install

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/vaila-multimodaltoolbox/vaila/main/install_vaila_mac.sh)"

Clone-first install (recommended)

git clone https://github.com/vaila-multimodaltoolbox/vaila.git
cd vaila
bash install_vaila_mac.sh

What install_vaila_mac.sh does

  1. Installs system dependencies via Homebrew; self-installs uv if missing.
  2. Pins Python 3.12.14.
  3. Prompts for optional extras (gpu/sam/sapiens/fifa as applicable to Apple hardware).
  4. Copies pyproject_macos.toml (Metal/MPS) over pyproject.toml before creating the virtual environment.
  5. Runs uv lock / uv sync --extra ... with fallback logic.
  6. Builds a full .app bundle (with icon conversion) for Applications/Launchpad.

GPU vs CPU-only

Apple Silicon uses Metal/MPS automatically via the general PyTorch stack; Intel Macs fall back to CPU-only. SAM 3 video requires NVIDIA CUDA at runtime and has no MPS/CPU path — not usable on macOS.

Troubleshooting

  • Homebrew missing: install it from brew.sh first, then re-run the script.
  • "App can't be opened because it is from an unidentified developer": right-click the .app in Applications and choose Open once to bypass Gatekeeper for an unsigned local build.

Running vailá after install

GUI: uv run vaila.py

CLI: see README's Running vailá — GUI and CLI section for per-module CLI invocation.

Updating / uninstalling: don't duplicate those steps here — see README's Staying up to date note and Uninstallation Instructions section, which stay the single source of truth.
