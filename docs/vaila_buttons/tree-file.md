# Tree - Button A_r1_c7

## Overview

**Button Position:** A_r1_c7
**Method Name:** `tree_file`
**Button Text:** Tree

## Usage

Fill the Source, Destination (when applicable) and filter fields, then **Preview**. Review the fixed target list, then **Apply preview**. Destructive operations require confirmation. Cancellation waits for the current file; the window stays responsive.

Essential messages always appear in the terminal. Diagnostic details enable --debug. The GUI prints a safely quoted equivalent CLI; removal commands default to --dry-run.

## CLI and outputs

Run **python -m vaila.filemanager tree --help** for arguments and an example. See the [File Manager guide](../../vaila/help/filemanager.md) for matching rules, output names, collision handling, permanent removal and SSH status.
