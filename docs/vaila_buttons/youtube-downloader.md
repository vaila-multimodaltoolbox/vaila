# YouTube Downloader - Video and Image

**Version:** 0.3.137
**Updated:** 2026-09-11

Load TXT or paste URLs into the editable list; choose destination and MP4/MP3, then Download. Loading TXT never starts downloads. Cancel, Open folder and Help remain accessible. Completion includes post-processing.

Run **python -m vaila.vaila_ytdown --help**. See the [YouTube Downloader guide](../../vaila/help/vaila_ytdown.md) for CLI examples, logs, output layout, quality policy and cancellation.
