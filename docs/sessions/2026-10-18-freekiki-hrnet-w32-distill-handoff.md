## 1. What was accomplished in this session

1. **HRNet-W32 Heatmap Architecture in pure PyTorch (`vaila/freekiki_heatmap.py`)**:
   - Implemented `HRNetW32` (`_HRBasicBlock`, `_HRBottleneck`, `_HRModule`) based on Sun et al. (CVPR 2019).
   - Keeps parallel multi-resolution branches (strides 4, 8, 16, 32 with 32, 64, 128, 256 channels) alive from stem to head.
   - Bilinearly upsamples all branches to stride 4 and concatenates into 480 channels, followed by a 1×1 conv (480 → 256) and a 1×1 conv head (256 → 49 keypoints).
   - Total model parameters: ~29.44M.
   - Dispatches cleanly via `KikiHeatNet(backbone="hrnet_w32", nkp=49)`.
   - `cached_imagenet_state("hrnet_w32")` searches local torch hub checkpoints for `*hrnet*w32*.pth`; if not present, gracefully returns `None` for Kaiming normal initialization without throwing `FileNotFoundError` (since teacher distillation provides the transfer).

2. **Knowledge Distillation Formula ($L = L_{gt} + \lambda L_{distill}$, default $\lambda = 0.5$)**:
   - Transfer learning from YOLO to HRNet cannot copy weights directly. The student learns from the teacher's soft predictions on the exact same augmented batch.
   - Implemented `render_soft_heatmaps` and `compute_distill_loss`.
   - `L_gt`: MSE vs ground-truth Gaussian heatmaps ($v=0 \implies$ zero map).
   - `L_distill`: MSE vs soft Gaussian heatmaps generated by the teacher evaluated on the exact same augmented canvas on GPU directly.
   - Where ground-truth $v=0$ but teacher confidence $\ge 0.2$, the student still receives a soft Gaussian target with amplitude equal to teacher confidence (inheriting predictions on unlabelled/missing points).
   - Where ground-truth $v>0$, ground truth remains dominant while distillation provides regularized soft targets.

3. **Frozen Teacher Builder (`build_teacher_fn`)**:
   - Evaluates on the student's normalized GPU tensor directly via `(x * STD + MEAN).clamp(0, 1)`.
   - Supports Ultralytics YOLO-pose checkpoints (`freekiki_l.pt`), FreeKiki heatmap checkpoints, `HeatmapPredictor`, or custom callables.
   - Converts teacher box-relative/canvas coordinates to cell coordinates `(uv + 0.5) / stride - 0.5`.

4. **FreeKiki CLI, Training Loop, and GUI Integration (`vaila/freekiki.py`)**:
   - Added `hrnet_w32` to `HEATMAP_SLOTS` with slot name `hm_hr32`.
   - Added `--teacher` and `--distill-weight` CLI options to `train`. For `hrnet_w32`, `--teacher` defaults to `active` (resolving to `models/freekiki_l.pt` in `/home/preto/data/FreeKiki`).
   - If a fresh workspace has no active model yet, it logs and safely falls back to ground-truth only.
   - `train_manifest.json`, `args.yaml`, and checkpoint metadata record `teacher`, `teacher_sha256`, and `distill_weight`.
   - `results.csv` logs `train/loss`, `train/loss_gt`, and `train/loss_distill`.
   - GUI: Heatmap preset sets `backend=heatmap`, `backbone=hrnet_w32`, `teacher=active`, `distill=0.5`. Heatmap backbone, teacher, and distill lambda controls exposed in Frame B.

## 2. Recommended Batch Size on 24 GB GPU (RTX 3090 / 4090)

- HRNet-W32 maintains high-resolution (stride 4, 8, 16, 32) feature maps across 4 parallel stages throughout the entire network.
- At 1024×576 canvas resolution:
  - `batch = 16` with live YOLO teacher + HRNet backwards graph exceeds 24 GB (OOM at backward pass).
  - `batch = 4` to `8` fits comfortably in 24 GB VRAM (`batch 4` uses ~14 GiB).
- **Recommendation for full training:** use `--batch 4` or `--batch 8`.
