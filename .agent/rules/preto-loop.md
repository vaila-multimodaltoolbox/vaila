# Preto Loop for Antigravity-compatible agents

This repository includes the portable `preto-loop` skill at `skills/preto-loop/SKILL.md`.

Load it when the user asks to write, create, specify, or harden an agent loop for biomechanics, data science, markerless/video analysis, or vailá code. Follow its interview, external-verification, scientific-validity, memory, budget, and terminal-state rules. The skill writes a loop specification; it does not execute the loop.

If the host uses a different Antigravity rule/workflow directory, copy this file and the `skills/preto-loop/` directory into that host's configured project rules location.
